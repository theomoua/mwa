# Projet Site Web Test

Ce projet est un site web simple qui affiche le message "test". 

## Structure du projet

Le projet contient les fichiers suivants :

- `index.html` : Point d'entrée du site web, affichant le message "test".
- `css/style.css` : Fichier de styles CSS pour la mise en page et le design.
- `js/script.js` : Fichier JavaScript pour ajouter des fonctionnalités interactives.

## Instructions d'exécution

1. Clonez ou téléchargez le projet sur votre machine.
2. Ouvrez le fichier `index.html` dans un navigateur web.
3. Vous devriez voir le message "test" affiché sur la page.

## Technologies utilisées

- HTML
- CSS
- JavaScript
